```powershell
cd "C:\Users\MEK\Desktop\py cloud\COURSE"

git init
git remote add origin https://github.com/KULLANICI_ADIN/COURSE.git
git add .
git commit -m "COURSE dosyaları eklendi"
```

```powershell
git pull origin main --allow-unrelated-histories
git push -u origin main
```

GitHub giriş ekranı açılırsa hesabınla giriş yap. Bundan sonra yeni dosya göndermek için yalnızca:

```powershell
git add .
git commit -m "Yeni dosya eklendi"
git push
```

VS Code’da `.gitignore` eklemek için:

1. Sol taraftaki **Explorer** bölümünde proje klasörüne sağ tıklayın.
2. **New File** seçeneğine tıklayın.
3. Dosya adını tam olarak yazın:

```text
.gitignore
```

4. Enter’a basın ve ignore etmek istediğiniz dosya/klasörleri ekleyin. Örneğin:

```gitignore
__pycache__/
*.pyc
.env
.vscode/
```

Git’in daha önce takip ettiği dosyalar varsa `.gitignore` sonradan onları gizlemez. Bu durumda terminalde:

```bash
git rm -r --cached .
git add .
git commit -m "Add gitignore"
```

Anladım: **sadece `.txt` dosyaları Git’e eklensin**, diğer dosyalar eklenmesin istiyorsunuz.

`.gitignore` içine şunları yazın:

```gitignore
*
!*/
!*.txt
!.gitignore
```

Anlamı:

- `*` → Her şeyi yok say
- `!*/` → Klasörlere erişime izin ver
- `!*.txt` → `.txt` dosyalarını Git’e dahil et
- `!.gitignore` → `.gitignore` dosyasını da dahil et

Sonra terminalde:

```bash
git add .
git status
```

`git status` çıktısında yalnızca `.txt` dosyalarını ve `.gitignore` dosyasını görmelisiniz. Git’e daha önce eklenmiş diğer dosyalar varsa onları takipten çıkarmak için:

```bash
git rm -r --cached .
git add .
```
